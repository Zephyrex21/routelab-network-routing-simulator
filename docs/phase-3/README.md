# Phase 3 — Core Routing Engine

Phase 3 implements the routing algorithms as pure JavaScript modules. It does not yet add simulation playback controls or packet animations to the interface; those are Phase 4 and Phase 5 work.

Read in order:

1. [`01-implementation-notes.md`](01-implementation-notes.md) — module boundaries, public API and execution model.
2. [`02-algorithm-and-event-contract.md`](02-algorithm-and-event-contract.md) — table semantics, event types, snapshots and metric definitions.
3. [`03-automated-and-manual-qa.md`](03-automated-and-manual-qa.md) — automated coverage and suggested local verification.
4. [`04-phase-3-signoff.md`](04-phase-3-signoff.md) — completed scope, evidence and Phase 4 handoff.

The authoritative behaviour specification remains [`../phase-0/05-algorithm-specification.md`](../phase-0/05-algorithm-specification.md).
