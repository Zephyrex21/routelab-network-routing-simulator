# 09 — Technical Reference Notes

Official documentation checked while selecting the initial tooling:

- Vite Getting Started: https://vite.dev/guide/ — project scaffolding and Node.js compatibility. Vite's current guide lists Node.js 20.19+ or 22.12+ for Vite.
- Tailwind CSS Vite integration: https://tailwindcss.com/docs/installation/using-vite — Tailwind CSS and `@tailwindcss/vite` setup.
- React Flow concepts: https://reactflow.dev/learn/concepts/building-a-flow — nodes, edges, viewport and installation of `@xyflow/react`.

These references explain tool setup; the product scope and algorithm rules in this repository are RouteLab's own design decisions, not requirements imposed by those libraries.
